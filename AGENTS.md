# Project guidance

Project: AI Werewolf, updated 2026-11-01.

Goal: improve AI-versus-AI Werewolf play and transparent model comparison while supporting human participation.

Stack: browser HTML, CSS and JavaScript in `index.html`; Cloudflare Pages Functions in `functions/api`.

Keep game rules deterministic, protect hidden information, and preserve existing user changes. Use the existing development scripts where applicable. Verify changes locally before deployment; do not deploy without an explicit request.
