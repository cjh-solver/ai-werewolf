# Provider logos

The SVG files in this folder are from [Lobe Icons](https://github.com/lobehub/lobe-icons), `@lobehub/icons-static-svg` version 1.97.0. They are included locally so the interface does not depend on a third-party image service. The collection's MIT license is in `LICENSE`.

The marks identify the respective model providers; their trademarks remain the property of their owners. `chatglm-color.svg` identifies Zhipu, and `ollama.svg` identifies local Ollama models. Custom providers use a neutral badge.
