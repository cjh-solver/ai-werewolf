# Project context

The primary goal is to watch different AI models compete and compare their performance; human participation is secondary. The desired character balance favors reasoning over human-like personality, approximately 60:40.

DeepSeek, Doubao, Qwen and Hunyuan are used, with Hunyuan used most often. Reasonable format correction is acceptable. Retries, model substitutions and fallback outcomes should be recorded transparently for review.

The desktop lobby should make key routing and optional browser storage clear beside the official console links. Keep token use and estimated cost visible without dominating the game interface; identify unsupported prices and incomplete usage instead of guessing.
